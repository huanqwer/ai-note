# 贡献指南

感谢您对 AI-Note 项目的关注！我们非常欢迎任何形式的贡献。

## 如何贡献

### 报告问题

如果您发现了 bug 或有新的功能建议，请：

1. 检查 [Issues](https://github.com/huanqwer/ai-note/issues) 页面，确认是否已有相同的问题
2. 如果没有，请创建一个新的 Issue，详细描述问题或建议

### 提交代码

1. Fork 本仓库
2. 创建您的特性分支 (`git checkout -b feature/AmazingFeature`)
3. 提交您的更改 (`git commit -m 'Add some AmazingFeature'`)
4. 推送到分支 (`git push origin feature/AmazingFeature`)
5. 开启一个 Pull Request

### 代码规范

- 保持代码风格一致
- 添加必要的注释
- 确保代码可运行
- 更新相关文档

### 文档贡献

- 修正错别字或语法错误
- 添加新的学习内容
- 改进现有内容的表达
- 翻译文档

## 许可证

通过贡献代码，您同意您的贡献将在 MIT 许可证下发布。

# Contributing Guidelines

Thank you for your interest in the AI-Note project! We welcome contributions in any form.

## How to Contribute

### Reporting Issues

If you find a bug or have a feature suggestion:

1. Check the [Issues](https://github.com/huanqwer/ai-note/issues) page to see if it has already been reported
2. If not, create a new Issue with a detailed description of the problem or suggestion

### Submitting Code

1. Fork this repository
2. Create your feature branch (`git checkout -b feature/AmazingFeature`)
3. Commit your changes (`git commit -m 'Add some AmazingFeature'`)
4. Push to the branch (`git push origin feature/AmazingFeature`)
5. Open a Pull Request

### Code Standards

- Maintain consistent code style
- Add necessary comments
- Ensure code is runnable
- Update relevant documentation

### Documentation Contributions

- Fix typos or grammatical errors
- Add new learning content
- Improve existing content expression
- Translate documentation
